# MLOps Dashboard (research demo)

A research and teaching demo of an MLOps dashboard: upload a scan, get the served CNN's answer with a
Grad-CAM heat map, and follow experiments, models, deployments and monitoring.

**Not a diagnostic device.** Do not upload real patient data.

Open the app at its direct link, `https://<username>-<space>.hf.space`. The site does not allow being
shown inside another page, so the preview on the huggingface.co Space page stays blank.

This Space repo is generated by `deploy/huggingface/bundle.sh` from the project repository; change the
project there and push a new bundle instead of editing files here. The model weights come from a
private model repo at start; the database is an external PostgreSQL (Neon). Secrets are Space secrets:
`DATABASE_URL`, `SESSION_SECRET`, `DEMO_USER_PASSWORD`, `COOKIE_SECURE`, `HF_TOKEN`, `MODEL_REPO`.
